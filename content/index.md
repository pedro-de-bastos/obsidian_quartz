# Welcome to your Quartz site!

This is a default page (`content/index.md`).

## Getting Started

1.  **Add your Obsidian Notes**: Copy your Obsidian vault content into the `content` directory of this repository.
    *   You can set this directory as your Obsidian Vault, or copy files manually.
2.  **Configuration**: Edit `quartz.config.ts` to change the site name, description, and other settings.
3.  **Deploy**: Push your changes to the `v4` branch of your GitHub repository.

See `README.md` for more details.
