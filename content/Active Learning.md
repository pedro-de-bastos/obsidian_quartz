An active learning framework (Koedinger et al., “Learning Is Not a Spectator Sport.”):
1. Learners first need examples (or a model) for how to do something
2. Learners then need to engage with activities and gain feedback + as-needed instruction which provides them with the scaffolding to gain expertise
3. The support/feedback has to be adaptive and advance the student's proficiency


“Active learning” is typically defined by educational researchers as learning that requires students to engage cognitively and meaningfully with the materials (Bonwell and Eison, 1991, as cited in Chi and Wylie, n.d)
